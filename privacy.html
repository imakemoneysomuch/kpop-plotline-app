Privacy policy

Last updated: 3 October 2026

KPOP Plotline is a local desktop uploader operated for the channel owner’s own YouTube workflow. This notice covers that personal uploader and this information website. Separate video-production applications and services have their own data practices.

1. Information the uploader handles

InformationPurpose and handling
Google authorizationOAuth access and refresh tokens, expiry information, granted scopes, and client configuration support authorized YouTube API requests. The operator signs in with Google; the uploader does not provide a password-collection form.
YouTube channel and upload informationThe channel ID and name, uploads playlist, video IDs, returned video metadata, visibility, and publication dates help verify the channel and find occupied scheduling slots.
Upload files and metadataThe prepared video, title, description, tags, category, language, audience declaration, visibility, publication time, and notification choice are used to submit the upload to YouTube.
Local operational recordsFile paths and checksums, approval and queue timestamps, job state, error messages, expected channel ID, video ID, watch URL, and scheduling receipts support validation, troubleshooting, and duplicate prevention. Source and rights records may be supplied with the upload package.

2. Google permissions and use

The uploader requests youtube.upload for video uploads and youtube.readonly for channel verification and scheduling checks. It uses YouTube API Services.

Google API data is used for the upload and scheduling functions described here. Its use and transfer are subject to the Google API Services User Data Policy, including the Limited Use requirements. The uploader does not sell Google API data or use it for advertising or external AI training.

3. Storage and protection

Credentials and operational records are saved in configured local files on the operator’s computer. The code attempts to restrict access through owner-only file and directory permissions. These files are not stored in this static website.

The uploader stores tokens in local JSON files and does not itself encrypt those files. Protection of the computer, disk encryption settings, backups, folder synchronization, and access by other people or tools are managed separately by the operator. A packaged upload can use a temporary local video copy that the program cleans up when that upload context exits normally.

4. Transfers and website visits

Google processes authorization requests. Video files and upload metadata are sent to YouTube when the operator runs an authorized upload; metadata is also retrieved from YouTube for the checks above. Google’s handling is described in the Google Privacy Policy.

The uploader’s authorization and video-upload requests are sent to Google and YouTube. Separate production tools, backups, and remote-support services are outside the scope of this uploader and must be managed separately by the operator.

This website is hosted on GitHub Pages. GitHub records and stores visitors’ IP addresses for security purposes, including visits made without signing into GitHub. See the GitHub Pages data-collection notice and the GitHub Privacy Statement. These pages do not add analytics scripts, advertising, embedded videos, cookies, or browser-storage code. Following an external link takes you to that provider’s site.

If you email the operator, your email provider and the operator’s mailbox process your address and message. Do not send passwords, OAuth tokens, or client-secret files.

5. Retention and deletion

The uploader stores credentials and work records locally and does not automatically delete them on a fixed schedule. Local tokens, queues, receipts, and job files remain until the operator manually removes or replaces them. YouTube stores uploaded content separately under its own controls.

Local data removal, including any separately managed backup copies, is handled manually by the operator. Revoking Google access does not start automatic deletion of those records.

To identify local records that need removal, contact zzangja0921@gmail.com with the channel or relevant job information. The operator handles deletion requests manually; the uploader has no self-service deletion control. Removing local records does not remove a video from YouTube.

6. Revoke Google access

You can withdraw the app’s access from your Google Account security permissions. Open the connected-app details for KPOP Plotline, review its access, and choose the access-removal option. Google provides current instructions for managing connected apps.

Revocation stops further authorized access but does not itself erase local records or delete published videos. Stop local upload jobs, handle local records separately with the operator, and use YouTube Studio to manage content already on YouTube. No new connection is created by reading this page.

7. Contact and changes

For privacy questions or concerns, contact KPOP Plotline 운영자 (KPOP Plotline operator) at zzangja0921@gmail.com. If the app’s data handling changes, this notice must be reviewed and updated before the changed handling is represented as part of the service.
